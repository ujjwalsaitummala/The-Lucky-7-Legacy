BEFORE YOU BEGIN

Terms & Privacy

Please read how The Lucky 7 Legacy works before continuing.

1. Local-first storage

This version does not use accounts, APIs, a backend, or a cloud database. When available, progress is stored in this browser's IndexedDB database, with a local-storage fallback. Data stays on this device and browser profile.

2. What is saved

Completed project IDs, GitHub repository URLs, optional notes, and your current mission are saved locally when auto-save is enabled.

3. Privacy and shared devices

Anyone with access to the same browser profile may be able to view saved progress. Do not put passwords, private tokens, or other sensitive information in project notes.

4. Data loss and backups

Clearing browser data, using private browsing, opening the downloaded file under a different browser origin, or changing devices/browsers may make progress unavailable. Local auto-save is not cloud sync. Export a JSON backup regularly to move or protect your progress.

5. Project links

You are responsible for the repository links and notes you submit. This demo records the link but does not verify repository contents or ownership.

6. Use and availability

The website is provided as a project-planning tool. Keep separate backups of anything important; browser storage is not guaranteed permanent.

You can continue only after checking the agreement box.

KEEP YOUR LEGACY

Choose your saving option

Before you start, choose how The Lucky 7 Legacy should remember your progress. This screen appears immediately after you agree to the Terms & Privacy notice.

What this enables

  • Save progress automatically as you spin, select, or complete projects.
  • Use IndexedDB (a browser database) when supported, with local-storage fallback.
  • Restore saved progress when you revisit the same site and browser profile.
  • No account, API key, or cloud service is needed.

What it does not do

  • It does not sync across devices or browsers.
  • It cannot protect against browser data being cleared or device loss.
  • For a separate backup file, use “Export progress” in the project panel.

Auto-save stores progress in this browser only; it is not a cloud backup. Once inside the site, use Export progress to download a separate backup file, or Import backup to restore one.
